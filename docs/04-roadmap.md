# Roadmap

## Now

- Configurable weekday cadence.
- Thread-safe Gmail replies.
- Sheet-backed state tracking.
- Public-safe documentation and sample data.

## Next

- Configurable delay windows instead of weekday-only timing.
- Template selection by campaign.
- Opt-out and unsubscribe handling.
- Structured execution log sheet.

## Later

- Dry-run mode with preview output.
- Admin dashboard for delivery and reply metrics.
- CRM integrations with explicit consent and audit logging.
